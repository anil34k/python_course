### Page 34 – Constructor Chaining
*   **Question:** Write a program to demonstrate constructor chaining with and without `super()`.
*   **Answer:**
    ```python
    # Without super()
    class Parent:
        def __init__(self):
            print("Parent Constructor")

    class Child(Parent):
        def __init__(self):
            # Explicit call using Parent class name
            Parent.__init__(self)
            print("Child Constructor")

    # With super()
    class ParentSuper:
        def __init__(self):
            print("Parent Constructor (super)")

    class ChildSuper(ParentSuper):
        def __init__(self):
            # Dynamic look up via super()
            super().__init__()
            print("Child Constructor (super)")

    print("--- Explicit Parent call ---")
    c = Child()
    print("\n--- super() call ---")
    cs = ChildSuper()
    ```
*   **Comments:** 
    *   Constructor chaining ensures that base class parameters/setup logic run before child initialization.
    *   Using `super().__init__()` is preferred as it dynamically resolved the hierarchy based on Method Resolution Order (MRO), which is essential in multiple inheritance.
    *   References: [Parent_Chain](file:///c:/Users/anilk/Desktop/Qspiders/python/oops.py#L743), [Child_Chain](file:///c:/Users/anilk/Desktop/Qspiders/python/oops.py#L748), [Parent_Super](file:///c:/Users/anilk/Desktop/Qspiders/python/oops.py#L763), [Child_Super](file:///c:/Users/anilk/Desktop/Qspiders/python/oops.py#L768).
